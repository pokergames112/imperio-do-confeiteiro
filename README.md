# Império do Confeiteiro — Catálogo Digital & Smart Checkout 🍰👑

Solução de **Catálogo Digital & Smart Checkout Mobile-First** desenvolvida para o cliente **Império do Confeiteiro** (Recife - PE) pela **PRIME RANK Marketing**.

---

## 🚀 Funcionalidades

- **📱 Mobile-First & Responsivo:** Experiência otimizada para smartphones com toque suave e navegação rápida.
- **🎨 Identidade Visual Exclusiva:** Paleta *Imperial Gold & Chocolate Real* inspirada na marca oficial.
- **🖼️ Carrossel de Banners:** Banners automáticos com suporte a swipe no celular e setas no desktop.
- **⚡ Categorias com Rolagem Suave:** Setas de navegação no computador e arrasto por toque no celular.
- **🏷️ Cálculo Dinâmico de Descontos:** Porcentagens de desconto (`% off`) calculadas automaticamente a partir dos preços de atacado e varejo.
- **🛒 Gaveta Lateral de Carrinho (*Cart Drawer*):** Visualização rápida de itens, quantidades e economia.
- **🚚 Cálculo de Frete em Tempo Real:** Consulta automática de CEP via API pública **ViaCEP**, com regras de entrega para Recife e Região Metropolitana + opção de *Retirar no Depósito (Grátis)*.
- **💳 Simulação de Pagamento Pix & Cartão:** Geração de QR Code Pix e Chave Copia e Cola instantânea.
- **📲 Disparo de Pedido Formatado no WhatsApp:** O pedido é estruturado e enviado diretamente para o WhatsApp oficial do cliente.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5 Semântico, CSS3 Moderno (Variáveis CSS, Flexbox, Grid), JavaScript Puro (ES6+ Modules)
- **APIs:** ViaCEP (Consulta de CEP e Logradouros)
- **Hospedagem Recomendada:** Vercel / GitHub Pages (100% Custo Zero)

---

## 💻 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/pokergames112/imperio-do-confeiteiro.git
cd imperio-do-confeiteiro
```

2. Inicie o servidor local:
```bash
node server.js
```

3. Acesse no navegador:
👉 `http://localhost:3000`
